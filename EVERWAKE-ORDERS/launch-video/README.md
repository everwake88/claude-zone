# Launch video

`everwake-orders-launch.mp4` — 46 seconds, 1920×1080, 30 fps, with a soft music bed.

| Time | Scene |
|---|---|
| 0–5 s | The Everwake mark draws itself: "Your WhatsApp, taking orders." |
| 5–20 s | A WhatsApp order at Nile Grill in Egyptian Arabic: dishes and prices, the free fries offer, a location pin, the confirmation |
| 20–30 s | The dashboard: the order rings in, "Accept and tell the customer", the customer hears it on WhatsApp |
| 30–36 s | Inbox, bookings, AI menu import, delivery zones, online payment, analytics |
| 36–41 s | The agent switch: off with one apology, on with "we're back" |
| 41–46 s | The Everwake lockup, everwake.tech |

The restaurant, dishes and prices are the demo restaurant in
`database/seed/demo_restaurant.sql`.

## Changing it

The whole video is one page, `video.html`. Every frame is a function of time,
so edit the words, the chat (`CHAT`), the orders (`ORDERS`) or the timings
(`SCENES`) there. Open it in a browser to preview it in real time (click to restart), then:

```sh
node render.cjs                      # writes everwake-orders-launch.mp4 (about 2 minutes)
node render.cjs --stills 3,14,24     # one PNG per second given, to check a moment quickly
```

Needs Node, Playwright with Chromium, and ffmpeg. The Arabic font is IBM Plex
Sans Arabic (`fonts/`, SIL Open Font License); the music is generated by ffmpeg,
so there is nothing to license.
